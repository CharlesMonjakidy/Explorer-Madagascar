# TOLIARA ÉVASION — Site touristique

## Lancer le site
1. Extraire le dossier `Toliara_Evasion`.
2. Ouvrir `index.html` dans un navigateur.
3. Aucune installation n'est nécessaire.

## Organisation
- `index.html` : structure et contenu des pages.
- `CSS/style.css` : couleurs, typographie et mise en page.
- `CSS/animations.css` : animations et apparitions.
- `CSS/responsive.css` : adaptation téléphone et tablette.
- `JS/script.js` : menu mobile, retour en haut et animations au défilement.
- `Asset/` : images locales utilisées par le site.

## Personnaliser les images
Remplace les fichiers de `Asset/` en gardant les mêmes noms pour conserver les liens :
- `lagon-ifaty.jpg`
- `pirogue-vezo.jpg`
- `baobabs-sud.jpg`
- `recif-corallien.jpg`

## À savoir avant publication
Ce projet est une vitrine touristique de démonstration. Le lien de contact ouvre le logiciel de messagerie de l'utilisateur ; aucun formulaire ne stocke ni n'envoie automatiquement des demandes. Avant une publication commerciale, remplace l'adresse de contact de démonstration et vérifie les informations pratiques, les autorisations d'images et les prestataires locaux.
